### 👋 **About Me**

I'm an **AI Engineer** working on agentic workflows, LLM automation and retrieval-augmented generation. Alongside that, I have 2+ years of enterprise experience on **Microsoft Dynamics 365 Commerce** and **Salesforce Commerce Cloud** at Cognizant, so I know how AI has to fit into real production systems.

- 🤖 Built an autonomous **agentic workflow** (Python + LLMs) that automates JIRA ticket triaging, intent classification and resolution routing
- ⚖️ Built **Samvidhan-Sathi**, a LangGraph-based legal aid agent with hybrid RAG and switchable cloud/local LLM inference
- 🎨 Built an **Intent-Driven Generative UI** where one LLM reads user intent and another builds the interface at runtime
- 🏢 Supported **200+ retail stores** on D365 Commerce and resolved 20+ CRM/loyalty issues weekly on SFCC
